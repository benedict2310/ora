# Ora Documentation

Ora documentation is reset around the v2 product direction.

## Current documentation

- [Architecture](architecture/README.md) — current system shape, boundaries, and architecture decision records.
- [Product](product/README.md) — current product scope, non-goals, and product decision records.

## Legacy documentation

The pre-v2 documentation archive lives in [legacy/v1/](legacy/v1/README.md). It is kept for historical reference only. Do not treat legacy stories, reports, or implementation logs as current source of truth unless a current ADR/PDR explicitly revives them.

## Documentation rules

- Current architecture decisions go in `docs/architecture/adrs/`.
- Current product decisions go in `docs/product/pdrs/`.
- Current overview/index material belongs in `docs/architecture/` or `docs/product/`.
- Avoid adding new story/report trees unless a current ADR/PDR creates that process.
