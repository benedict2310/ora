# Legacy v1 Documentation Archive

This directory contains pre-v2 documentation moved out of the current documentation surface during the Ora v2 reset.

## Status

Historical reference only.

Do not treat files in this archive as current product or architecture direction unless a current PDR/ADR explicitly revives them.

## Why this archive exists

Ora v1 accumulated many stories, reports, references, and implementation notes across a broad product surface. Those docs are valuable history, but keeping them in the main documentation tree made it hard to see the current product direction.

The current source of truth is now:

- `docs/product/` for product overview and PDRs.
- `docs/architecture/` for architecture overview and ADRs.

## Archived material

- `stories/` — legacy implementation stories and old PRD/architecture docs.
- `reports/` — legacy investigations and status reports.
- `references/` — legacy design and implementation references.
- `profiling/` — legacy profiling notes.
- `research/` — legacy research notes.
- `media/` — legacy media assets.
- `RELEASE-PROCESS.md` — legacy release process notes.
